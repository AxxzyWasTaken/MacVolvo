# MacVolvo 1.0

<!-- minimum-macos: 26.5 -->

**Release candidate — test package, not Developer ID signed or notarized.**
The draft download is intended for review. It is not eligible for MacVolvo's
automatic updater. A signed, notarized public installer remains pending.

## What's new

- Play and Open Steam remain visible while a game is running. Open Steam focuses
  Steam rather than the game; Play returns to the already running game.
- Per-game resolutions, custom sizes and fullscreen options sync to Steam Properties.
- Black-and-white icon, solid backgrounds and a monochrome launcher.
- Raw mouse timing no longer depends on diagnostic logging being enabled.
- Fixed a captured fullscreen display-lock deadlock and improved launch handoff.
- CS2 uses a default 120 FPS cap (preserving an existing user launch cap) and
  a separate shader-worker setting. These are mitigations, not a measured fix
  for combat spikes.

## Download and install

Use assets attached to [MacVolvo Releases](https://github.com/haeli05/MacVolvo/releases),
not GitHub's automatically generated “Source code” archives, to install the app.
For the test package, extract `MacVolvo-1.0-unsigned.zip` and move `MacVolvo.app`
to Applications. macOS may block this unnotarized package. The signed public
download will be named `MacVolvo-1.0.dmg` when available.

Requirements: Apple Silicon, macOS 26.5+, Rosetta, a Steam account and internet
access. Allow about 70 GB per game; 16 GB RAM recommended. Intel Macs are not supported.

## Known issues

1. **Black screen with sound on launch:** quit the game completely and restart it.
   This can occur through MacVolvo or Steam; intermittent cases remain unresolved.
2. **Audio static:** in Audio MIDI Setup, choose Window → Show Audio Devices,
   select the output device and set Format to **96,000 Hz (96 kHz)** if supported.
   Quit and restart the game. This helped on the tested M2 Max; it is not a universal fix.
3. **CS2 combat lag spikes or sustained severe FPS loss:** investigation continues.
4. **Deadlock mouse pan stops after a match:** quit and restart the game.
   Post-match recovery has not been fully verified.
5. Steam store/profile pages may flicker while loading.

## Validation and limits

A native regression test detects the old fullscreen self-lock and passes with
its deferred-query repair. One launch on the repaired runtime recorded actual
native presentations. Repeated-launch stability and full-match input behavior
remain player-test items; no CS2 combat benchmark improvement is claimed.
